# 🎬 Movie Website

Bu loyiha — filmlar haqida ma’lumot beruvchi oddiy va zamonaviy **Movie Website**. Sayt frontend texnologiyalar asosida ishlab chiqilgan bo‘lib, foydalanuvchilarga filmlarni ko‘rish, qidirish va ular haqida qisqacha ma’lumot olish imkonini beradi.

## 🚀 Texnologiyalar
Loyihada quyidagi texnologiyalardan foydalanilgan:
- HTML5  
- CSS3  
- JavaScript  

## ✨ Funksiyalar
- 🎥 Filmlar ro‘yxatini ko‘rsatish  
- 🔍 Film nomi bo‘yicha qidiruv  
- 📝 Film haqida qisqacha ma’lumot  
- 📱 Responsive dizayn (mobil va desktop uchun mos)
